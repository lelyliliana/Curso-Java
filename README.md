# Curso de Java desde cero

**Versión 1.0**

Curso abierto para aprender **Java de forma progresiva**, desde la sintaxis fundamental y la programación orientada a objetos hasta colecciones, programación funcional, concurrencia, redes, pruebas y construcción de proyectos con Maven.

Este curso está diseñado como un recurso independiente dentro de Aprende con Leli.

## Requisito recomendado

[Curso de Algoritmos y Lógica de Programación](https://github.com/lelyliliana/Curso-Algoritmos)

No es obligatorio dominar otro lenguaje.

## Objetivo

Al finalizar podrás:

- configurar un entorno moderno de desarrollo Java;
- comprender compilación, JVM y ejecución;
- utilizar variables, tipos, operadores y control de flujo;
- diseñar clases y objetos;
- aplicar encapsulamiento, herencia, composición, interfaces y polimorfismo;
- manejar excepciones;
- trabajar con cadenas, fechas y archivos;
- utilizar colecciones y genéricos;
- aplicar lambdas y Stream API;
- comprender concurrencia y sincronización;
- crear aplicaciones cliente-servidor básicas;
- utilizar Maven;
- escribir pruebas automatizadas;
- organizar proyectos mantenibles;
- construir un proyecto final completo.

## Versión de referencia

Los ejemplos se orientan a **Java 21 LTS** y evitan depender innecesariamente de características experimentales.

## Lo que este curso no intenta ser

Este repositorio enseña **Java**. Frameworks y áreas especializadas se mantienen como cursos independientes para que Java no se convierta en una colección interminable de tecnologías.

## Principio

> Aprende primero el lenguaje y sus modelos; después utiliza frameworks con criterio.
