# Unidad 30 — Proyecto final

## Propósito
Construir una aplicación Java de consola o servicio local que integre lenguaje, POO, colecciones, persistencia en archivos o comunicación según el problema.

## Requisitos
- Maven;
- modelo de dominio;
- encapsulamiento;
- colecciones;
- manejo de errores;
- configuración separada cuando aplique;
- pruebas JUnit;
- Mockito cuando exista una dependencia apropiada;
- logging/diagnóstico;
- README reproducible.

## Opcionales según problema
- Streams;
- concurrencia;
- sockets;
- NIO.

## No es obligatorio usar todo
La calidad no se mide por cantidad de características. Utiliza cada herramienta solo cuando resuelve una necesidad real.

## Cierre
> Java profesional no consiste en usar todas las APIs del lenguaje, sino en construir software que pueda comprenderse, probarse y mantenerse.
