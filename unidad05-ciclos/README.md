# Unidad 05 — Ciclos

## for
```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

## while
```java
while (saldo > 0) {
    // proceso
}
```

## do-while
Ejecuta el cuerpo al menos una vez.

## for-each
```java
for (int valor : valores) {
    System.out.println(valor);
}
```

## Contadores y acumuladores
```java
int cantidad = 0;
double suma = 0;
```

## Riesgo
Un while cuya condición nunca cambia puede convertirse en ciclo infinito.
