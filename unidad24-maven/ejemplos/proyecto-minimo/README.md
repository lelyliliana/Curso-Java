# Proyecto mínimo Maven
Requisitos: JDK 21 y Maven 3.9.16. Abre una terminal en esta carpeta.
1. Ejecuta `mvn test`: dos pruebas del saludo.
2. Ejecuta `mvn package`: compila, prueba y empaqueta.
3. Ejecuta `java -jar target/java-unidad24-1.1.0.jar`: imprime `Hola, Java`.
El JAR no necesita JUnit ni Mockito en ejecución. El manifiesto contiene la clase de entrada. [Volver a la unidad](../../README.md).
