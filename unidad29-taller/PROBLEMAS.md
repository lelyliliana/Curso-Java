# Taller integrador Java

Los problemas no indican qué API utilizar.

## 1. Importador
Lee registros desde archivo. Conserva válidos y reporta inválidos.

## 2. Catálogo
Altas, consultas, filtros y estadísticas.

## 3. Notificaciones
Varias implementaciones detrás de un contrato.

## 4. Agenda
Fechas, conflictos y ordenamiento.

## 5. Analítica
Procesa una colección de transacciones de forma imperativa y con Streams.

## 6. Trabajo concurrente
Ejecuta tareas independientes y recopila resultados/errores.

## 7. Red local
Cliente/servidor con protocolo documentado.

## 8. Aplicación Maven
Integra dominio, servicio y pruebas.

## Entrega
Para cada problema:
- modelo;
- decisiones;
- código;
- pruebas;
- errores;
- alternativa considerada;
- instrucciones de ejecución.
