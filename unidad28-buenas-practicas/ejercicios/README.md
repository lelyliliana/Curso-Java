# Taller de refactorización

Busca y mejora:
1. método de 100 líneas;
2. nombres x/a/tmp;
3. booleanos ambiguos;
4. duplicación de reglas;
5. clase con demasiadas responsabilidades;
6. dependencia creada internamente que impide pruebas.

## Proceso
- crea prueba;
- aplica un cambio pequeño;
- ejecuta pruebas;
- repite.

## Reto
Documenta un refactor antes/después explicando qué propiedad de diseño mejoró.
