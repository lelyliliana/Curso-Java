# Referencias oficiales

Las lecciones usan Java 21 como contrato de compilación, aunque los proveedores ofrecen versiones posteriores. Las versiones de herramientas y bibliotecas se fijan en los pom.xml; una actualización debe verificarse, no hacerse solamente cambiando números.

| Tema | Fuente primaria |
|---|---|
| Lenguaje, tipos y aprendizaje | [Dev.java](https://dev.java/learn/) |
| Reglas precisas del lenguaje | [Java Language Specification 21](https://docs.oracle.com/javase/specs/jls/se21/html/index.html) |
| Bibliotecas del JDK | [API Java SE 21](https://docs.oracle.com/en/java/javase/21/docs/api/index.html) |
| Importes y comparación decimal | [BigDecimal](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/math/BigDecimal.html) |
| Records y mutabilidad superficial | [Record](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Record.html) |
| Hilos virtuales | [JEP 444](https://openjdk.org/jeps/444) |
| Fases y dependencias | [Maven Getting Started](https://maven.apache.org/guides/getting-started/) |
| Compilación release | [Maven Compiler Plugin](https://maven.apache.org/plugins/maven-compiler-plugin/) |
| Pruebas | [JUnit User Guide](https://docs.junit.org/6.1.3/overview.html) |
| Ejecutor de pruebas | [Maven Surefire](https://maven.apache.org/surefire/maven-surefire-plugin/) |
| Dobles e instrumentación en Java 21 | [Mockito, documentación del proyecto](https://github.com/mockito/mockito/blob/main/mockito-core/src/main/java/org/mockito/Mockito.java) |
