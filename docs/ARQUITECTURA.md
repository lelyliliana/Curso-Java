# Arquitectura pedagógica

## Alcance

Curso de lenguaje Java, no de frameworks.

## Separación de responsabilidades

Java cubre:
- lenguaje;
- POO;
- biblioteca estándar;
- colecciones;
- funcional;
- concurrencia;
- redes;
- herramientas y pruebas.

Cursos independientes pueden cubrir tecnologías especializadas sin modificar este repositorio.

## Estructura sugerida por unidad

```text
unidadXX-tema/
├── README.md
├── ejemplos/
├── ejercicios/
└── reto/
```

## Reglas editoriales

- Java 21 LTS como referencia.
- Ejemplos pequeños y ejecutables.
- Explicar primero la idea.
- No introducir frameworks para enseñar conceptos del lenguaje.
- No prometer contenido futuro.
- No depender de referencias institucionales.
- Separar código de producción y pruebas cuando corresponda.
