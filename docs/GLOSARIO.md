# Glosario de Java

| Concepto | Significado en este curso |
|---|---|
| JDK | Kit de desarrollo con compilador y herramientas |
| JVM | Máquina virtual que ejecuta bytecode compatible |
| Bytecode | Instrucciones del formato de clase |
| JIT | Compilación de código durante la ejecución de la JVM |
| Primitivo | Valor de un tipo básico, como int o boolean |
| Referencia | Valor que permite alcanzar un objeto o representa null |
| Identidad | Dos referencias apuntan al mismo objeto |
| Igualdad | Relación definida por equals para el tipo |
| Aliasing | Varias referencias alcanzan el mismo objeto |
| Constructor | Inicialización de una instancia según un contrato |
| Invariante | Regla que se mantiene en cada estado válido observable |
| Encapsulamiento | Control del acceso y de las operaciones que preservan el modelo |
| Composición | Un objeto colabora con otros objetos |
| Herencia | Relación de subtipo con requisitos de sustitución |
| Polimorfismo | Uso de implementaciones mediante un contrato común |
| Record | Tipo de datos con componentes y métodos generados |
| Enum | Tipo con un conjunto declarado de constantes |
| Copia superficial | Copia de estructura que mantiene referencias a elementos |
| Excepción checked | La compilación exige declarar o manejar según sus reglas |
| Causa | Excepción de origen conservada al propagar otro fallo |
| Genérico | Tipo o método parametrizado por tipos |
| PECS | Productor extends, consumidor super |
| Lambda | Expresión de comportamiento con interfaz funcional objetivo |
| Terminal | Operación que consume un stream |
| Optional | Contenedor de un valor presente o ausente |
| Instant | Punto de la línea temporal |
| ZoneId | Identificador y reglas de zona horaria |
| Atomicidad | Una operación se observa como unidad indivisible bajo su contrato |
| Visibilidad | Garantías de observación de escrituras entre hilos |
| Interrupción | Señal cooperativa para coordinación y cancelación |
| Future | Resultado futuro o fallo de una tarea |
| Framing | Regla para delimitar mensajes dentro de un flujo |
| Maven | Herramienta de construcción y resolución de dependencias |
| Scope test | Dependencia disponible para pruebas, no para la app final |
| Stub | Respuesta configurada para un colaborador de prueba |
| Mock | Doble configurable que puede verificar interacciones |
| Refactorización | Cambio estructural que conserva comportamiento contratado |
