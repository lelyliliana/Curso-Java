## Trece extensiones independientes

Abre la carpeta solucion de la unidad elegida. Ejecuta cada comando por separado:

```text
javac -encoding UTF-8 --release 21 Solucion.java
```

```text
java Solucion
```

Los archivos de unidades distintas usan el mismo nombre de clase y se compilan por separado. El verificador utiliza directorios temporales aislados, con UTF-8 y objetivo Java 21, para contrastar sus salidas con casos normales, fronteras y rechazos.
