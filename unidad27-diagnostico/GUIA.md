# Método de diagnóstico

## 1. Reproduce
Define entrada y pasos.

## 2. Observa
Error, stack trace, logs, estado.

## 3. Formula hipótesis
No cambies código todavía.

## 4. Reduce
Crea el caso mínimo que mantiene el fallo.

## 5. Instrumenta
Debugger/logs/tests.

## 6. Corrige una causa

## 7. Verifica
Ejecuta el caso original y regresiones.

## Stack trace
Lee desde la excepción y localiza la primera línea de tu código relevante. No empieces cambiando dependencias al azar.
