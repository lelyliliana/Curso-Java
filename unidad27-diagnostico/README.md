# Unidad 27 — Logging, depuración y configuración

## Logging
Distingue niveles conceptuales:
- error;
- warn;
- info;
- debug/trace.

No uses System.out como sistema de logging en aplicaciones que requieren observabilidad estructurada.

## Depurador
Breakpoints, step over, step into, watches.

## Configuración
No hardcodees rutas, credenciales o valores que cambian por entorno.

## Excepciones
Conserva causa/contexto útil.

## Reto
Diagnostica un programa defectuoso usando debugger y logs, documentando hipótesis y evidencia.
